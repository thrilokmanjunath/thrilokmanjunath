## Featured Projects

### 🧠 [Synthetic Silence](https://github.com/thrilokmanjunath/Synthetic_Silence)
Explainable multi-agent hallucination and knowledge-void detection platform for LLMs using Topological Data Analysis and Sparse Autoencoders. Mathematically identifies when an LLM claim falls outside the topological structure of verified human knowledge.

`Python` `PyTorch` `Multi-Agent` `Sparse Autoencoder` `TDA` `AI Safety` `LLM`

---

### 🚀 [Nexus-One](https://github.com/thrilokmanjunath/Nexus-One)
Unified full-stack AI platform for Data Science, ML, GenAI, and Multi-Agent Orchestration. Next.js frontend, FastAPI backend, LiteLLM multi-provider routing, Docker microservices.

`Next.js` `FastAPI` `Python` `TypeScript` `LiteLLM` `Docker` `MLOps`

---

### ⚡ [EV Battery Quantum](https://github.com/thrilokmanjunath/EV_Battery_Quantum)
Hybrid Quantum-Classical ML framework for multi-objective EV battery pack design optimisation. Uses QAOA for Pareto-optimal configurations and QKSVM for predictive performance modelling, with Celery workers, Redis caching, WebSocket streaming, and Prometheus observability.

`Python` `QAOA` `QKSVM` `FastAPI` `Celery` `Redis` `Docker` `Prometheus`

---

### 🐯 [Eyes on Tigers](https://github.com/thrilokmanjunath/Eyes-on-Tigers)
AI-powered conservation analytics platform evaluating Project Tiger reserves via Computer Vision, Google Earth Engine satellite telemetry, and spatial ML. Computes a Tiger Success Index (TSI) to track habitat integrity.

`Python` `PyTorch` `Computer Vision` `Google Earth Engine` `Streamlit` `Remote Sensing`

---

### 📚 [PaperMate AI](https://github.com/thrilokmanjunath/PaperGraph) · [Live Demo ↗](https://paper-graph-wine.vercel.app)
Research intelligence platform with interactive citation knowledge graphs, AI-generated literature reviews, and paper search. Built with Next.js frontend and Java Spring Boot backend.

`Next.js` `Java` `Spring Boot` `PostgreSQL` `Redis` `Docker` `Knowledge Graph`

---

### 🗄️ [RepoBase](https://github.com/thrilokmanjunath/RepoBase) · [Live Demo ↗](https://repo-base-iota.vercel.app)
Premium developer workspace SPA for repository management. Features a Command Palette (⌘K), glassmorphism UI, and deterministic visual identities for projects. Django backend with PostgreSQL.
